# S13 · 宝牌造型第二版（精绘）验收归档

> 起点：用户反馈「宝牌的样式还不够精美，**这三种颜色可以**，
> 但是其中的图案太粗糙了（指铁砧），帮我继续美化，更精细、更美观一些」。
> 本轮**只改器物造型**，三套配色（`zhu` / `wu` / `sajin`）原样保留、仍未拍板。

---

## 一、改了什么：从"一块色疙瘩"到"一件有体积的器物"

v2 每件器物是**一条大路径 + 一两条描线**。放大看就是"一块色疙瘩上划一道"：

| 症状 | 表现 |
|---|---|
| 没有明暗 | 读不出体积，像剪纸贴上去的 |
| 没有结构 | 铁砧分不出砧面/砧腰/砧座；竹篓分不出经纬 |
| 轮廓线细且半透明 | 128px 下直接消失（`stroke-width 8~10`、`opacity .35~.5`） |
| 造型本身错 | 竹篓**上小下大**（像灯罩）；陶罐双耳只探出 20 单位（≈2px）；算盘框比珠子还壮 |

v3 换了一套**绘画语言**，不是"把线画细一点"（那在 128px 下只会糊）：

1. **组合块面**：一件器物由若干基本块拼成（砧面/砧腰/砧座/砧足各是一条路径）。
   比例好调，改一处不带崩全局 —— v2 的一条大路径改一笔就可能自交。
2. **三档色阶**：主色 `motif` / 暗面 `motifSh` / 亮面 `motifHi`。
   **精细在小尺寸下靠的是块面对比，不是线条**：线条缩到 128px 是灰雾，块面缩下去还是块面。
3. **剪影外描边**：把所有 `base` 路径先用 24 宽描一遍、再把填充盖上去，
   于是只剩"外轮廓的外半边" —— 器物从漆面上"起"出来。
   （先描后填还顺手解决了"组合块面内部接缝会不会显线"。）
4. **接触投影**：器物底下压一枚 `feGaussianBlur` 椭圆，落在漆面上而不是浮在漆面上。
5. **结构细节**：砧孔（方+圆）、花瓶口内腔、算珠顶光、竹篓经纬、灯焰内焰 ——
   每件给 1~3 处**高对比小特征**。这是"像不像"的关键，也是 64px 下唯一还能辨认的东西。

**关键实现：用 `clipPath` 把暗面/亮面裁进剪影。**
暗面亮面只写"大致位置"（一根竖带、一段椭圆环），形状不必贴着轮廓；
一旦出界就会在漆面上留一块游离色斑 —— 而它**不报错**，只是难看。
用 `base` 当剪裁形状，出界部分自动切掉：**几何可以写糙，结果一定干净**。

## 二、逐件对照（`造型对照-八件器物.png` / `造型对照-铁砧.png`）

| 器物 | v2 的问题 | v3 的改法 |
|---|---|---|
| **铁砧** | 一条路径，砧角是从砧面上下**对称收尖** → 渲出来是一片"柳叶/刀片" | 拆成 5 块（角/面/腰/座/足）；角改成**上缘几乎平着出去、下缘往里收**、尖端留 36 厚度；砧面加厚到 100；加砧孔（方+圆）两处特征 |
| **花瓶** | 一个瓶形色块，读不出是不是容器 | 加**口内腔**（深色椭圆）+ 两道颈环 + 腹弦；左右月牙做体积 |
| **水盆** | 与果盘撞形（都是碗） | 折沿外撇 + 腹更浅 + **口内腔**；果盘则靠"三枚带梗带叶的果实 + 高足"分开 |
| **果盘** | 三个光圆，像汤圆 | 每颗果实配梗+叶；左右月牙；盘下加高足 |
| **竹篓** | ①上小下大（灯罩）；②经线用亮色 → 5 条白条压在底上，读成"纱窗" | ①改**口大底小的桶形**；②经纬**都用暗色**，在浅色篓身上织出深色格纹；③线宽 22~24 → 16 |
| **陶罐** | 双耳只探出 20 单位、环孔只剩十几单位 → "两个凸起" | 耳改成**显式 C 形带**：外弧探出 ~74、环孔 ≥40（128px 下 ≈4.5px）；两端埋在罐身里 |
| **灯盏** | 灯盘是一块梯形，像"两块叠起来的板" | 盘口加亮边；内焰加宽到外焰的一半；柱上束腰 |
| **算盘** | ①框太厚（80）比珠子（54）还壮；②珠子正圆、上下贴死 → 连成柱子；③4 档 → 珠柱间留 66 单位漆面 → 四扇"窗" | ①框收到 46~42；②珠子压成**扁圆 66×44**、上下留 17~25 的缝，**直档从缝里露出来**；③改 **6 档**、档距 96 |

## 三、用途符合性对比（按"提示词/素材必须先写用途再逐条验收"的约定）

**用途**：微信小游戏《挪字成章》**宝牌牌面**；烘焙为 128×128 PNG，
盘面上约以 53~64px 显示；与 248 张字牌**同盘混排**。

| # | 判据 | 结论 | 依据 |
|---|---|---|---|
| 1 | 比例 / 尺寸 | ✅ | 1000×1000 画布 → 128×128 位图，与字牌一致（8 张全部实测 128×128） |
| 2 | 安全区 | ✅ | 器物按 `fit=0.56` 居中，四周留白充裕，无任何元素压到描金框/回纹/角标 |
| 3 | 可叠字空间 | ✅ | 宝牌不叠字（文字由引擎 toast 说明），无需留位 |
| 4 | 是否遮挡关键信息 | ✅ | 素材层无遮挡（**盘面上**"器物显形压住赠品牌"是表现层问题，见 §七） |
| 5 | 乱码 / 水印 / 商业文案 | ✅ | 图形为矢量路径，无文字、无水印、无品牌 |
| 6 | 是否脱离宣纸调子 | ✅ | 与字牌**同一张纸**（同色 + 同 `#chenZhi` / `#xianWei` 两滤镜）；见 `烘焙核对-与字牌1比1混排.png` |
| 7 | 扫视时能否跳出 | ✅ | 全盘只有宝牌是"深色实心块"，与字牌并排时一眼可辨（`宝牌试样-v3.png` §②） |
| 8 | 64px 下能否辨认 | ✅ | §② 64px 混盘与 §④ 96px 撞形对照，八件都不撞形 |

**本轮判定：适合**（不需要第 2 轮微调）。

## 五、本轮踩的坑（都是"静默"的）

1. **★ `fill="undefined"` 不是报错，是渲染成黑** —— 我给 `zhu`/`wu` 加了 `shadow` 色位，
   漏了 `sajin`。SVG 对非法 `fill` 的处置是**丢弃或落到默认黑**，
   于是症状是"洒金宣那张宝牌底下压了一块黑斑"，没人能从一个色斑联想到"色表少了一个键"。
   修法：`svg()` 开头**逐一点名校验色位**，缺了就在构建期抛错。
2. **★ `shiftPath` 不能把数字两两配对去加偏移** —— 路径里除了坐标还有别的数字：
   `A 27 27 0 1 0 347 360` 里 `27 27` 是半径、`0 1 0` 是大弧/扫向标志。
   两两配对会把弧的 flags 一起平移 → 算珠画歪或干脆不显示，**静默坏**。
   修法：按**命令**逐段处理（M/L 每 2 个数一对、C 每 6 个、A 每 7 个且只动最后两个）。
3. **相邻两块"不同深度的亮带"会在交界处立一道竖缝** —— 砧角的亮带比砧面的深，
   两者在 x=260 相接，放大看像拼接。修法：让亮带**越过**交界再被剪影裁掉，而不是两块拼起来。
4. **`document.querySelector('svg')` 命中的是隐藏的滤镜定义 `<svg>`** ——
   对照图第一次出图右边整块空白。修法：选 `svg[data-tr]`。
   （同理：任何"页面上有多个 svg"的截图页，都必须用属性选择器定位。）
