拖动跟手 —— 像素级实测（2026-10-02）
==============================================================
数据源：/tmp/s5-feel2/11-feel-mid.png（拖到插值 60% 时、**松手前**截的那一帧）
场景  ：L3（seed:1）第一次拖拽，[Diag] SUGGEST 从=丈@3,3 到=3,2
        即 丈 从「列3」挪到「列2」，同一行（设计 y=-164）

屏幕坐标口径：原点左上，画布 600×1260，中心 (300,630)，
             设计单位→屏幕 px 缩放 PS = 600/720 = 0.8333

【参照值】
  起点格中心  x = 346.7      （设计 x = +56）
  目标格中心  x = 253.3      （设计 x = -56）
  两者相差      93.3         （= 一格 112 设计单位 × 0.8333）
  拖拽插值 10 段、midAt = round(10×0.55) = 6 → 实际进度 60%
  → 60% 时手指应在 x = 346.7 + (253.3−346.7)×0.60 = 290.7

【实测】按"纸面亮区"（亮度≥205）分段测量被拖那张牌：
  纸面段 x 244..337，宽 93，中心 290.5
  （宽 93 = 一格 85.0 × 1.1 —— 与 DRAG_SCALE 1.1 的"拎起来"状态吻合）

【结论】
  | 与手指位置 290.7 | 差 −0.2 px |  ← 跟手 |
  | 与目标格中心 253.3 | 差 +37.2 px | ← 不是吸附 |
  | 与起点格中心 346.7 | 差 −56.2 px | ← 不是吸附 |

  → 牌停在**手指所在的位置**（误差 0.2px，小于 1 个像素），
    **不是**"一格一跳"地吸附到某个格中心。
    这正是本轮把 onMove 从「setPosition(cellX/cellY 的整数格中心)」
    改成「沿锁定轴用手指真实位置 + 另一轴锁死 + 越界橡皮筋」的效果。
