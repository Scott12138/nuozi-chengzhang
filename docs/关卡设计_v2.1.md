# 《挪字成章》关卡设计 v2.1（定稿）

> **起因**：需求方提出两条 ——「每一关的字种类太少了，会让人玩得疲劳」「不能全是同一个偏旁，要对关卡进行合理设计」。
> **范围**：本稿**只定「每一关用哪些字、这些字的偏旁怎么搭」**。
> 棋盘尺寸 / 配对数 / 干扰牌数 / 限时 **一律沿用规格书 §2.11 原值，未动分毫。**
> **状态**：四条决策已拍板（见 §2），全 38 关字单已铺满并通过校验（`0 违规`）。

---

## 0. 先说清病在哪（实测，不是感觉）

写了 `tools/level-audit.js` 直接读原型里真正在跑的 32 关复算牌堆：

| 指标 | 实测值 | 问题 |
| --- | --- | --- |
| 平均每关**字种数** | **3.88 个** | 一关只有三四个字，看两眼就认全了 |
| 平均**不同牌面图案** | **9.1 种** | 一关 21～44 张牌，撑起画面的只有 9 种图案 |
| **清一色单一偏旁**的关 | **14 / 32 关** | 接近一半的关卡整关只有一种偏旁 |
| 最单调的一张牌面 | 「木」在一关里出现 **9～11 张（43%）**；第三章「鱼」出现 **14 张（45%）** | 21 张牌里 9 张一模一样 |
| 一章 8 关实际有几种**不同字单** | **3 种** | 第 2 关和第 3 关**逐字相同**，体验完全一样 |
| 全库 **103 字**实际用到 | **20 字** | **88 个字从未在游戏里出现过** |

**根因（三条，全在原型的程序化生成里，不是"设计不用心"）**

1. `nx = i<3 ? 3 : (i<6 ? 4 : 5)` —— 字种数被**硬编码**在 3～5，永远不增长。
2. `words = pool.slice(0, nx)` —— **永远从字池第 0 个开始切**，于是第 6、7、8 关拿到同一批字，**逐字相同**。
3. 字池是**按偏旁分组排列**的（章一前 8 个全是「木」），从第 0 个切 → **每关必然清一色一个偏旁**。

一句话：**"字种少"和"偏旁单一"是同一个 bug 的两个症状。**

> 附带发现：规格书 §2.11.2 那张难度曲线表其实**已经写对了一半**（有「1-5 偏旁置换点」），
> 但原型是程序化生成的，**两者从未对齐过**。

> **本稿真正的落点**：关卡字单必须是**"设计出来的"**，不能是**"算出来的"**。
> 现在这套程序化生成，本身就是"越玩越像"的根源。

## 1. 六条设计原则（全部可脚本验收）

### R1 字种数随进度递增，不再硬编码

```
字种数 = min( 配对数 , round( 章底盘 + 章内序号 × 0.55 ) )
章底盘：第一章 4 ／ 第二章 5 ／ 第三章 5 ／ 第四章 6
```
- 上夹理由：**字种数 ≤ 配对数**，否则有字一局里一对都凑不出，目标栏会出现 0/0。
- 全期曲线 **4 → 9**，全期平均 **7.03 个/关**（现状 3.88）。

### R2 每关至少 2 个偏旁（★ 杠杆比"加字种"更大）

> 同一个偏旁的字共用同一张偏旁牌。一关里若 5 个木旁字，就要铺 5 张以上「木」。
> 所以**光加字种数治不了单调**。
> 实测：8 个木旁字、12 对 → 「木」占 **43%**；换成木4 + 钅4、同样 12 对 → 「木」只占 **21%**。

### R3 单张牌面重复率 ≤ 30%（最硬的验收指标）

「一关里出现次数最多的那张牌 ÷ 本关总牌数 ≤ 30%」。这一条同时管住 R1 与 R2。

### R4 章内孤偏旁豁免，但每关 ≤ 3 个

有些字在**本章内**的偏旁只此一个（章一：竹→箭、父→斧、奴→弩、佥→剑）。
它们不是配错了，而是本作的**第二条教学轴**：「**形旁跑到右边/下边去了**」
（剑 = 佥 + 刂，刂 才是形旁；斧 = 父 + 斤，斤 才是形旁）。

> ⚠️ 必须按**章内**统计。`竹` 全库 6 个字（章四的箱筐篮筷笼都是竹字头），但章一只有「箭」一个。

**唯一的明示豁免**：3-8「鸟字组」需要 4 个章内孤偏旁（合我昔甲），这是该专题的本质而非失误，
已在数据里写明 `exempt` 理由。

### R5 同一关内，一个字不能既当偏旁又当部件（硬约束）

配对规则要求**一偏旁 + 一部件**（`a.kind === b.kind` 直接判不合法）。
而水墨版已经把偏旁牌/部件牌的**冷暖双色去掉了**（配对表无序，颜色不带玩法信息）。
所以若一关里「虫」既作偏旁（蚂 = 虫 + 马）又作部件（烛 = 火 + 虫），
玩家会看到**两张一模一样的「虫」，行为却不同** —— 不可接受。

→ 排关时按字求交：**本关所有偏旁字 ∩ 本关所有部件字 = 空集**。
（此规则在铺关时真的拦下了一次事故：3-9 原本同时放了 鲤/鲸 与 鲨 = 沙+鱼，`鱼` 一关里既是偏旁又是部件。）

### R6 数值表不动

棋盘 / 对数 / 干扰牌数 / 限时**一律沿用 §2.11 原值**。需求方早前明确说过"关卡数值表先不动" ——
动了就是把两件事搅在一起，无法判断是哪一处起效。

## 4. 抗疲劳的六种手法（交替出现，不是每关都全套）

| # | 手法 | 出现位置 | 效果 |
| --- | --- | --- | --- |
| 1 | **字种递增** 4→9 | 全程 | 基础量，治"看两眼就认全" |
| 2 | **偏旁混排** 每关 2~3 个 | 全程 | 治"刷屏一个偏旁"，**杠杆最大** |
| 3 | **偏旁换血点** 每 2~3 关 | 1-3、2-4、3-7、4-3 | 打断"先找某个偏旁"的视觉惯性 |
| 4 | **章末综合关** | 1-8、2-8、3-12、4-10 | 不加新内容，全章偏旁混排，限时最短 |
| 5 | **专题关** | 见下 | 让「偏旁决定类别」被真正撞见 |
| 6 | **非内容变化** | 1-4 起 | 撤提示条、限时递减、棋盘变大 —— 不加新字也能改变体感 |

**专题关清单**
