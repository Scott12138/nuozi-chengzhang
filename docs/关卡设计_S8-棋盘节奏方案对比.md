## 一、现状诊断（三条与预想不同的事实）

| # | 事实 | 影响 |

**根因**：现状盘面占用率一路涨到 **94%**（L38 只剩 3 个空格）。这玩法要「滑动 + 对齐消除」，**盘面塞满 = 每张牌上下左右全被堵 = 一步都动不了**。所以下面所有方案都把 **空置率** 当一级指标，锁在 **25%~33%**。

## 二、计算口径（三个公式）

```
占用率   occ   = 0.70 + 0.08 × (n − 1) / 37      // L1 70% → L38 78%
宝牌对数 tr    = clamp( floor((格数 − 24) / 16) + 1, 1, 3 )   // 30/36格→1对、42/48格→2对、56/64格→3对
配对数   pairs = floor(格数 × occ / 2) − tr
```

- **宝牌**：每对 2 张，上限 3 对 —— 满足你「两两成对、最多不超过 3 对、按总格子比例」。
- **配对数**：保证「占用率稳定在 70~78%」，即**空格永远留够**。
- **限时暂未调整**（沿用现值），见 §五 待拍点 ④。
